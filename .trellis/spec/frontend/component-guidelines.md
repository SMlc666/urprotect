# Component Guidelines

## Scope

The repository currently contains no frontend components or UI framework. The
CLI's `CliApplication.PrintUsage` and human-readable output are terminal
presentation code, not reusable browser components.

Do not introduce component conventions, styling libraries, or accessibility
claims for code that does not exist. A future frontend task must define its
component model, props, composition, styling, keyboard behavior, and accessible
name/focus rules from its selected framework.
