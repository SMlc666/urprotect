## Contracts and report boundaries

- `SemanticTargetResolution` has `Exact`, `BoundedSet`, `RuntimeResolved`, and `Unresolved` (`src/UrProtect.Core/SemanticPlanning/SemanticValueModels.cs:7-13`). A bounded target set remains a set; layout/runtime resolution must not collapse it merely because one candidate currently maps (`.trellis/spec/backend/runtime-compatibility.md:935-938`). Fixup state (`Resolved`/`Deferred`/`Unresolved`) is a separate dimension (`runtime-compatibility.md:956-959` and design note `design.md:212`).
- `AddressMapEntry` carries typed source and output ranges, each retaining both `FileOffset` and `VirtualAddress` (`src/UrProtect.Core/SemanticPlanning/AddressMap.cs:7-32`). Address-map rows are not a substitute for the per-entry `jumpTableTargetBindings` that additionally bind source/output target, base, and encoded value.
- The in-image jump-table source plan sets the indirect branch target to `BoundedSet`, then gives each table entry and the default target an `Exact` target identity (`src/UrProtect.Core/SemanticPlanning/Aarch64SemanticPlanFactory.cs:1263-1290,1517-1585`). The evidence string `bounded-relative-table` is a report label, not the enum token `BoundedSet`.
- Layout schema-v3 ownership is a different enum from semantic target resolution: JSON codes are `Ambiguous=0`, `SelectedFunctionPrivate=1`, `Shared=2`, `External=3`, `RuntimeOwned=4` (`runtime-compatibility.md:921-927`). The report should keep ownership, resolution mode, fixup state, and output mapping in distinct columns.
- The CLI has no general cross-row semantic report projection. `ProtectedImageCommandReport` exposes role/stage/path/diagnostics (`src/UrProtect.Cli/Rendering/ProtectedImageCommandReport.cs:7-31`); `ProductProtectionReport` exposes input, passes, functions, output and diagnostics, not target modes/maps (`ProductReport.cs:108-149,237-295`); `RehydrationCommandReport` wraps a rehydration record/native descriptor/diagnostics (`RehydrationCommandReport.cs:7-23`). The final general report should be a separately identified task/evidence summary; it should not be described as an existing CLI JSON field.
