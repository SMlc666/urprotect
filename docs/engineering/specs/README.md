# Engineering Specifications

These specifications are project-owned engineering contracts. The indexes
below describe their scope and point to the detailed rules.

- [Backend](./backend/index.md): production architecture, binary safety,
  diagnostics, semantic planning, evidence, and runtime compatibility.
- [Frontend](./frontend/index.md): current frontend non-applicability and the
  conditions for introducing a frontend safely.
- [Guides](./guides/index.md): code ownership/reuse and cross-layer contract
  reasoning.

The authoritative overview and maintenance rules are in
[`docs/engineering/README.md`](../README.md).
